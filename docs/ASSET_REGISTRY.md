## Rebuild
```bash
python -m venv .venv-cad && .venv-cad/Scripts/pip install cascadio trimesh fast-simplification pillow
.venv-cad/Scripts/python scripts/cad/raw_convert.py source-assets-private/cad/<file>.stp source-assets-private/preview-glb/raw/<ID>.raw.glb 0.3
.venv-cad/Scripts/python scripts/cad/build_preview_glb.py <ID> <raw.glb> <source.stp> <out.glb> <report.json>
.venv-cad/Scripts/python scripts/cad/render_views.py <out.glb> <prefix> 420 --color   # 6-view QA sheet
```
