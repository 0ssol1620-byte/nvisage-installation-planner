## 2. 정성 비교 — 아직 레퍼런스가 앞서는 부분
1. **골퍼 사실감**: GSV는 실사 인체 모델을 쓰고, 우리는 원통·구로 만든 마네킹입니다. 자세와 궤적은 같은 운동학 모델에서 나와 서로 일치하지만, 외형은 GSV가 더 자연스럽습니다. 라이선스가 확인된 리깅 캐릭터(CC0 또는 구매)를 받으면 같은 IK 데이터로 교체할 수 있습니다.
2. **장비 DB**: GSV는 인클로저·프로젝터·매트 실제 제품을 고를 수 있고, 우리는 치수와 투사비를 직접 입력해야 합니다.
3. **장애물**: 아직 구현하지 않았습니다.

## 3. NVISAGE 플래너가 앞서는 부분
- 센서 위치·높이·히팅존을 **NVISAGE 공식 매뉴얼 수치와 페이지 출처**로 판정합니다. 인용 26건을 PDF 원문과 자동 대조했습니다.
- 오버헤드 센서와 프로젝터 투사광의 간섭(화면 그림자)을 판정합니다.
- 실제 CAD에서 만든 제품 모델을 씁니다(개발 서버). 배포 빌드에서는 비공개 게이트가 CAD 노출을 막습니다.
- 한국어/영어, m/ft-in 전환을 지원합니다.
